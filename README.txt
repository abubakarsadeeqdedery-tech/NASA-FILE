ZUNO: Junior Astronaut Mission Trainer (updated)

GODADDY (cPanel Web Hosting)
1. Log in to GoDaddy > My Products > Web Hosting > Manage > cPanel Admin > File Manager.
2. Open the public_html folder and delete the default placeholder page.
3. Upload index.html (this file) into public_html.
4. Turn on SSL (SSL/TLS Status > Run AutoSSL), then open https://yourdomain.com

NOTES
- Needs internet (3D library loads from jsDelivr).
- Live NASA solar-flare reading shows inside the Solar dust demo when hosted online.
- Progress and stickers are saved in the player's browser. Use "Start over" to reset.
